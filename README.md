# Circle

**Find your Circle.** A community-first support platform for people living
gluten-free — celiac disease and gluten intolerance — that works globally.

Built with Next.js 15, React, TypeScript, Tailwind CSS, and Prisma. See
[`AGENTS.md`](./AGENTS.md) for development and run instructions.

## Quick start

```bash
npm install
cp .env.example .env   # auto-created on cloud startup
npx prisma db push
npx prisma db seed
npm run dev            # http://localhost:3000
```

Demo login: `maya@circle.app` / `password123` (admin: `admin@circle.app`).
