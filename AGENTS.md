# Gluten Free Collective

A community-driven support platform for people with celiac disease and gluten
intolerance. Full-stack **Next.js 15** (App Router) + **TypeScript** + **Tailwind CSS**
+ **Prisma**.

Modules: Community Hub (feed), MSN-style Chat, Safe Restaurant Directory (map),
Local Community Map, Recipes, Product Database, Mental Health Center, AI Celiac
Assistant, Travel Mode, Premium membership, Doctor/Dietitian + Knowledge Center,
and an Admin dashboard.

## Cursor Cloud specific instructions

### Running the app
- Dev server: `npm run dev` → http://localhost:3000 (single Next.js process serves
  both UI and API routes / server actions; there is no separate backend service).
- Standard scripts live in `package.json`: `npm run dev`, `npm run build`,
  `npm run lint`, `npm run typecheck`.

### Database (important, non-obvious)
- **Local dev uses SQLite** (`prisma/schema.prisma` → `provider = "sqlite"`,
  `DATABASE_URL="file:./dev.db"`) for a zero-config setup. The **production target
  is PostgreSQL / Supabase** — to deploy, switch the provider to `postgresql` and
  point `DATABASE_URL` at your Postgres instance.
- `prisma/dev.db` is gitignored and recreated from scratch by the update script
  (`prisma db push` + seed). It is safe to delete.
- Reset the database to clean seeded state: `npm run db:reset`.
- After editing `prisma/schema.prisma`, run `npx prisma db push` then restart the
  dev server (Prisma Client is regenerated by `db push` / `postinstall`).
- `.env` is gitignored; the update script auto-creates it from `.env.example` if
  missing. All values in `.env.example` are safe local-dev defaults.

### Optional integrations — all have working mock fallbacks (no keys required)
- **Maps** use keyless **MapLibre GL + OpenStreetMap raster tiles** (no Mapbox
  token needed). `NEXT_PUBLIC_MAPBOX_TOKEN` is optional.
- **AI Celiac Assistant**: if `OPENAI_API_KEY` is set it calls OpenAI; otherwise a
  built-in rule-based assistant answers (with cited sources). See `src/lib/ai.ts`.
- **Premium / Stripe**: if `STRIPE_SECRET_KEY` is set, wire real Stripe in
  `src/lib/actions/premium.ts`; otherwise upgrade is simulated so the premium flow
  is fully testable.

### Real-time chat & presence (non-obvious)
- Chat, typing indicators, and online presence are implemented with **HTTP polling**
  (`src/components/chat-window.tsx` polls `/api/chat/[roomId]/messages` every ~2.5s;
  `src/components/presence-heartbeat.tsx` pings `/api/presence`). There is **no
  standalone WebSocket server** — this keeps dev single-process. A user is shown
  "online" if their `lastSeen` is within the last 60s.

### Auth
- Custom cookie/JWT session (`src/lib/auth.ts`, `jose` + `bcryptjs`). The session
  cookie is `gfc_session`. `/app/*` routes require a session and redirect to `/login`.
